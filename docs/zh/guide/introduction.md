# 文档介绍

当前站点已调整为更接近常见产品文档门户的结构。

## 当前体验

- 更简洁的顶部导航、搜索与主题切换。
- 更明确的侧边栏分组，区分指南与参考内容。
- 顶部更新提示条，用于说明文档仍在持续维护。
- 提供英文与简体中文两个入口。

## 建议阅读路径

1. 从首页进入。
2. 继续阅读 [快速开始](/zh/guide/getting-started)。
3. 如果你维护站点，再查看 [部署说明](/zh/guide/deployment)。
4. 需要实现细节时阅读 [运行时 API](/zh/api-examples)。

## 为什么要改

原来的界面更强调终端风格。现在的版本更强调可读性、目录浏览效率和双语文档体验，更接近传统产品文档站的使用方式。
