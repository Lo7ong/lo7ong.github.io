# Introduction

This site now follows a more standard documentation pattern similar to product docs portals.

## Included experience

- A cleaner navigation bar with search and theme switching.
- A structured sidebar for guide and reference content.
- A top notice banner for ongoing documentation updates.
- Parallel English and Simplified Chinese entry points.

## Reading flow

1. Start on the home page.
2. Read [Getting Started](/guide/getting-started).
3. Continue to [Deployment](/guide/deployment) if you maintain the site.
4. Use [Runtime API](/api-examples) for implementation details.

## Why the change matters

The previous interface leaned heavily into terminal styling. The refreshed version makes the site feel closer to a conventional documentation portal, which improves scanning, navigation, and bilingual discoverability.
